# 시간 조각 대모험

쉬는 시간용 한국사 RPG. 포켓몬 골드 형식, 재미 80% · 공부 20%. 아이스크림 사회 5-2 수준.
지금 들어 있는 스테이지: **구석기부터 광복·현대까지 10개 시대 전부 + 엔딩**

## 조작

| 키 | 하는 일 |
| --- | --- |
| 방향키 (또는 WASD) | 걷기, 메뉴 고르기 |
| 스페이스 / Z / 엔터 | 말 걸기, 결정 |
| X / 백스페이스 | 취소 · 누르고 걸으면 달리기 |
| Esc | 메뉴 (동료, 도감, 가방, 연표, 기록 카드, 저장, 설정) |
| F9 | 개발자 모드 (비밀번호 필요, 선생님 테스트용) |
| F8 | 비밀번호로 개발자 모드를 연 뒤, 미니게임·배틀 중에 누르면 바로 성공 |

저장은 자동입니다 (지도 이동, 배틀 후, 30초마다). 기기를 바꿀 때는 메뉴 → 설정 → 저장 코드.

## 구석기 스테이지 흐름 (쉬는 시간 10분 안팎)

화면 왼쪽 위 「목표」가 다음에 할 일을, 사람 머리 위 「!」가 말을 걸 사람을 알려 줍니다. 꼭 해야 하는 배틀은 마지막 부족장전 한 번뿐입니다.

1. 할아버지 연구실 → 타임머신 사고 → 강가 막집 마을
2. 마을 어른에게 첫 동료 고르기 (주먹도끼 / 돌창 / 불씨)
3. 마을 일 세 가지 돕기 (순서 자유)
   - 채집: 숲에서 열매·도토리·버섯을 줍고 뿌리를 캐기, 독버섯 피하기 (35초)
   - 매머드 사냥: 사냥꾼들과 함께 창을 던져 5번 맞히기 (45초) → 찍개가 동료로
   - 막집 짓기: 나뭇가지 → 끈 → 가죽 → 돌 순서로 재료 고르기 → 긁개가 동료로
4. 동쪽 큰 동굴: 부족장 퀴즈 3문제 → 부족장 배틀 → 뗀석기 인장, 칭호 「구석기 사냥꾼」
5. 타임머신 → 다음 시대로

더 하고 싶은 학생은 북쪽 들판 풀숲(가끔 유물이 튀어나옴)에서 도감을 채우고 반짝이 유물을 찾을 수 있습니다.

## 전체 스테이지 (한 시대 = 쉬는 시간 한 번, 약 10분)

| # | 시대 | 형식 | 할 일 (거점) | 스승 · 인장 · 칭호 |
| --- | --- | --- | --- | --- |
| 1 | 구석기 | 마을 | 채집 · 매머드 사냥 · 막집 짓기 | 부족장 · 뗀석기 인장 · 구석기 사냥꾼 |
| 2 | 신석기 | 마을 | 빗살무늬 토기 빚기 · 작살 낚시 · 갈돌로 곡식 갈기 | 촌장 · 간석기 인장 · 신석기 농부 |
| 3 | 청동기·고조선 | 마을 | 덮개돌 밀기 퍼즐 · 벼 베기 · 8조법 재판 | 단군왕검 · 고조선 전사 |
| 4 | 삼국·가야 | 걷는 맵 (한강 나루 → 고구려·백제·신라·가야) | 살수 물길 퍼즐 · 백제 바닷길 · 가야 대장간 · 진흥왕 문답 | 광개토대왕 · 삼국 영웅 |
| 5 | 남북국 | 걷는 맵 (서라벌 → 불국사·청해진·발해) | 불국사 다른 곳 찾기 · 신종 종소리 리듬 · 장보고 무역 | 대조영 · 바다의 상인 |
| 6 | 고려 | 걷는 맵 (개경·벽란도 → 귀주·남쪽 절 마을·강진) | 서희의 담판 · 상감 무늬 파기 · 기록 짝 맞추기 · 거울 글자(금속 활자) | 강감찬 · 고려 장인 |
| 7 | 조선 | 걷는 맵 (한양 → 의령·한산도) | 한글 조합 · 측우기 · 의병 곽재우 몰래 길 | 이순신(이기면 거북선이 동료로) · 조선 선비 |
| 8 | 조선 후기 | 지도 | 수원 화성 성벽 쌓기 · 김정호 지도 조각 퍼즐 · 보부상 장터 · 김홍도 씨름 | 정약용 · 실학자 |
| 9 | 일제 강점기 | 걷는 맵 (경성 → 평양·아우내·상하이) | 독립 선언서 전하기 · 태극기 완성 · 말모이 낱말 분류 | 김구(퀴즈만, 배틀 없음) · 독립의 등불 |
| 10 | 광복·현대 | 걷는 맵 (서울 → 광주·동해 바닷가 「시간의 틈」) | 연표 줄 세우기 · 6·25 전쟁 작전 지도 · 민주주의 | 시간 괴물 대왕(모든 시대 퀴즈 5문제) → 엔딩 크레딧 · 한국사 박사 |

삼국 시대부터는 「작은 한반도」를 걸어 다닙니다. 가운데 마을(한강 나루·서라벌·개경·한양·경성·서울)에서 길을 따라 동서남북으로 가면 다른 지역 맵이 나옵니다. 예) 삼국: 북쪽 고구려, 서쪽 백제, 동쪽 신라, 남쪽 가야. 머리 위에 ! 가 뜬 사람의 일을 모두 도우면 스승을 만날 수 있습니다.
조선 후기와 6·25 전쟁만 한반도 지도 위에서 진행합니다(조선 후기는 지도형 시대, 6·25는 현대 시대 안의 작전 지도 미션).
시간 괴물은 모든 시대의 방해꾼입니다. 사람끼리 싸우는 장면은 넣지 않았습니다.
역사 내용(대사·퀴즈·해설)은 `docs/역사내용-신석기부터현대까지.md`에 모아 두었습니다.

## 조작법

| 키보드 | 태블릿 버튼 | 하는 일 |
| --- | --- | --- |
| 방향키 | 방향 버튼 | 걷기 |
| X를 누른 채 방향키 | B를 누른 채 방향 버튼 | 빨리 달리기 |
| 스페이스 (Z, 엔터) | A | 말 걸기 · 살펴보기 · 결정 |
| X (백스페이스) | B | 취소 |
| Esc | 메뉴 | 메뉴 (동료 · 가방 · 저장) |

게임을 처음 시작하면 구석기 마을에 도착했을 때 한 번 안내합니다. 이미 하던 기록은 다음 시대에 도착할 때 한 번 보여 줍니다.

## 풀숲 배틀 횟수
이어진 풀숲 한 덩어리에서는 유물이 최대 3번만 튀어나옵니다. 그 뒤로는 그 풀숲을 걸어도 배틀이 나오지 않습니다. 횟수는 `engine/scenes/world.js` 맨 위의 `HG.GRASS_MAX`로 바꿀 수 있습니다.

## 시간 지킴이 점수
엔딩에서 총점과 칭호가 나오고, 메뉴 → 기록 카드에서도 지금 점수를 볼 수 있습니다. 많이 플레이한 것보다 지식을 쌓은 것에 점수를 더 줍니다.

| 항목 | 점수 |
| --- | --- |
| 퀴즈 정답 (서로 다른 문제, 같은 문제는 한 번만) | 문제당 40점 |
| 숨은 보물 / 길가 보물 | 30점 / 50점 |
| 모은 유물 (도감) | 종류당 20점 |
| 시대 인장 | 30점 |
| 동료 전투력 (레벨 + 경험치) | 1당 2점 |

칭호는 총점 등급(꼬마 시간 여행자 · 시간 탐험가 1500 · 역사 수호자 2500 · 전설의 시간 지킴이 3500)과 가장 잘한 부문(역사 박사 · 보물 탐험가 · 유물 수집가 · 시간 용사) 두 가지가 붙습니다. 점수 배분은 `engine/score.js`에서 바꿀 수 있습니다.

## 숨은 보물 (이스터에그)

맵의 모든 것(집·물건·사람·나무·바위·물·꽃밭…) 앞에서 A(스페이스)를 누르면 무언가 반응합니다. 그중 몇 곳에는 보물이 숨어 있어 처음 한 번 아이템, 반짝이 동료, 그 장소에 얽힌 역사 이야기 한 줄을 얻습니다. 보물 자리는 표시하지 않습니다. 찾으면 찾는 것, 못 찾으면 못 찾는 것 — 구석구석 살펴보는 재미를 위해서입니다. 메뉴 → 기록 카드에서 모은 수만 볼 수 있습니다.

**길에서 발견하는 보물**: 나무·바위·물·논밭 같은 자연물을 살펴볼 때 아주 낮은 확률(5%)로 국보급 보물이 나옵니다. 실제로 우연히 발견된 문화유산 이야기(전곡리 주먹도끼, 백제 금동대향로, 금관총, 석가탑 다라니경, 신안 해저 유물, 훈민정음 해례본 등)와 "문화유산을 발견하면 꼭 신고해요"를 함께 알려 줍니다. 같은 자리를 연달아 살펴보거나 몇 걸음 걷지 않고 다시 살펴보면 나오지 않아서, 연타가 아니라 돌아다니며 살펴봐야 찾을 수 있습니다. 확률은 `engine/secret.js`의 `CHANCE`로 바꿀 수 있습니다.

**인물 옷차림**: 시대마다 한복(저고리 깃·고름, 치마, 두루마기)을 입히고, 대표 인물은 상징 옷을 입혔습니다. 세종대왕은 곤룡포와 익선관, 이순신·광개토대왕·강감찬은 투구와 갑옷, 근초고왕·진흥왕은 금관, 선비는 갓, 관리는 복두를 씁니다. 크기는 그대로입니다. 조선 후기를 뺀 모든 시대에 들어 있습니다.

## 태블릿

터치 화면에서는 방향 버튼과 A·B·메뉴 버튼이 저절로 나옵니다. 가로로 놓고 하세요. 홈 화면에 추가하면 전체 화면으로 열립니다.

## 개발자 모드 (선생님 확인용)

첫 화면, 마을, 지도 어디서든 **F9** (또는 Ctrl+Shift+D)를 누르면 비밀번호 창이 뜨고, 비밀번호를 맞히면 개발자 메뉴가 열립니다. 비밀번호는 `engine/main.js` 맨 위의 `HG.DEV_PASSWORD`에서 바꿀 수 있습니다(처음 값은 선생님께 따로 알려 드림). 한 번 열면 페이지를 새로 고칠 때까지 유지되고, F8(바로 성공)도 그때부터만 동작합니다. 키보드가 없는 태블릿에서는 열 수 없습니다.

| 메뉴 | 하는 일 |
| --- | --- |
| 시대 이동 | 고른 시대의 처음으로 바로 갑니다 (앞 시대는 깬 것으로, 동료 레벨도 맞춰 줌) |
| 미니게임 바로 해 보기 | 시대 → 거점을 고르면 그 미니게임만 바로 해 보고 원래 화면으로 돌아옵니다 |
| 거점 모두 완료 / 스승 앞으로 가기 | 지도형 시대(조선 후기)에서 스승전만 바로 확인할 때 |
| 마을 일 모두 완료 | 마을·걷는 맵 시대에서 스승전만 확인할 때 |
| 숨은 보물 보기 | 보물 자리 표시(★ 못 찾음 · ✓ 찾음), 길가 보물 확률 100% 켜기, 이 시대 보물 다시 숨기기 |
| 스승 앞으로 가기 (걷는 맵) | 걷는 맵 시대에서 스승 바로 앞으로 순간 이동 |
| 이 시대 클리어 상태로 | 인장과 칭호를 받은 상태로 만들기 |
| 도우미 기능 | 무적, 동료 레벨 +5, 이 시대 유물 전부, 고기 10개 |
| 엔딩 크레딧 보기 | 엔딩만 확인 |

개발자 메뉴를 한 번 열면 그때부터 미니게임 화면 오른쪽 아래에 「F8 바로 성공」이 보이고, **F8**로 지금 하는 미니게임이나 배틀을 바로 통과할 수 있습니다. 새로 고침하면 꺼집니다.

## 미니게임 종류

같은 방식은 많아야 두 번만 나오도록 시대마다 다른 놀이를 넣었습니다.

| 종류 | 나오는 곳 |
| --- | --- |
| 줍기 | 구석기 채집, 고조선 벼 베기, 조선 측우기 |
| 순서 고르기 | 구석기 막집, 신석기 토기 |
| 타이밍 / 연타 | 신석기 곡식 갈기, 가야 대장간 / 조선 후기 씨름 |
| 사냥 · 배 몰기 · 장사 · 몰래 가기 | 매머드 사냥 · 백제 바닷길 · 장보고, 보부상 · 의병, 독립 선언서 |
| 새로 만든 14종 | 작살 낚시, 덮개돌 밀기, 물길 퍼즐, 다른 곳 찾기, 종소리 리듬, 무늬 따라 파기, 기록 짝 맞추기, 거울 글자, 한글 조합, 성벽 쌓기, 지도 조각 퍼즐, 태극기 완성, 낱말 분류, 연표 줄 세우기 |

## 6·25 전쟁 작전 지도

현대 시대의 서울에서 피란민 할머니를 도우면 진행합니다(약 8분). 선생님은 개발자 메뉴 → 미니게임 바로 해 보기 → 광복·현대에서 바로 해 볼 수 있습니다.
전국 지도 위에서 전선과 화살표가 움직이며 전쟁의 흐름을 보여 주고, 사이사이 미니게임 3개를 합니다.
피란민 돕기 → 낙동강 방어선 지키기 → 인천 상륙 작전 → 1·4 후퇴 → 정전 협정·휴전선 → 이산가족 이야기 → 퀴즈 3문제

## 폴더 구조

```
index.html                  게임 시작 파일
engine/                     모든 스테이지가 같이 쓰는 엔진 (걷기·대화·배틀·사냥·메뉴·저장·소리)
  scenes/mini-*.js          새 미니게임 14종 (mini-base.js 가 공통 틀)
  scenes/                   장면별 코드
data/                       유물·기술·속성·연표 목록
stages/01-paleolithic/      구석기 지도·대사·퀴즈(stage.js)와 그림(art.js)
stages/02-neolithic/ ~ 09-colonial/   시대마다 한 폴더 (stage.js 하나에 그림·대사·퀴즈)
stages/10-korean-war/       6·25 전쟁 작전 지도 (현대 스테이지에서 씀)
stages/10-modern/           광복·현대 + 마지막 결전
docs/                       기획서 사본, 스테이지별 역사 내용 검수표
vendor/phaser.min.js        게임 도구 (Phaser 3.80.1)
fonts/                      갈무리 글꼴 (SIL 오픈 폰트 라이선스)
```

대사나 퀴즈를 고칠 때는 해당 시대 폴더의 `stage.js`만 고치면 됩니다. 퀴즈는 보기 중 **첫 번째가 정답**이고, 게임에서는 순서가 섞여 나옵니다.

## GitHub Pages로 올리기

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소 Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 정하고 저장합니다.
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 열립니다.
