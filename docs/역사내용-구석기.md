# 구석기 스테이지 — 게임에 나온 역사 내용 (선생님 검수용)

아이스크림 사회 5-2 교과서와 대조해 주세요. 고칠 곳은 `stages/01-paleolithic/stage.js`(대사·퀴즈)와 `data/artifacts.js`(도감 설명)에 있습니다.

## 1. 사실로 전달하는 내용

| 어디서 | 내용 | 확인 |
| --- | --- | --- |
| 돌 깨는 사람 | 돌을 깨뜨리거나 떼어 내서 만든 도구 = 뗀석기. 주먹도끼·찍개·긁개 모두 뗀석기 | ☐ |
| 불 지키는 사람 | 불로 추위를 막고, 음식을 익혀 먹고, 짐승을 쫓음 | ☐ |
| 채집하는 사람 | 열매를 따고 뿌리를 캐는 것 = 채집 | ☐ |
| 아이 | 먹을 것이 떨어지면 옮겨 다님(이동 생활), 동굴이나 막집에서 삶 | ☐ |
| 막집 | 나뭇가지를 세우고 짐승 가죽을 덮어 만든 집 | ☐ |
| 사냥꾼 대장 | 큰 짐승(매머드)은 여럿이 힘을 모아 사냥, 잡은 것은 나눔 | ☐ |
| 채집 미니게임 | 열매·도토리·버섯을 모으고 뿌리를 캠. 먹을 수 있는 것과 없는 것(독버섯)을 가려야 함 | ☐ |
| 막집 짓기 미니게임 | 나뭇가지로 뼈대 → 위쪽을 끈으로 묶음 → 짐승 가죽을 덮음 → 돌로 아래를 누름. 금방 짓고 걷을 수 있어 옮겨 다니는 생활에 맞음 | ☐ 재료·순서가 교과서 설명과 맞는지 |
| 찍개·긁개 동료 | 사냥한 고기를 손질하던 찍개, 가죽을 다듬던 긁개 | ☐ |
| 부족장 | 구석기 사람들은 무리를 지어 함께 사냥하고 나누며 살았음 | ☐ |
| 마을 어른(클리어 후) | 훗날 돌을 갈아 더 정교한 도구를 만들게 됨 (신석기 예고) | ☐ |

## 2. 도감 설명

| 유물 | 설명 | 확인 |
| --- | --- | --- |
| 주먹도끼 | 돌을 깨뜨려 만든 뗀석기. 사냥, 가죽 벗기기 등 여러 가지로 씀. 연천 전곡리에서 발견 | ☐ |
| 돌창 | 나무 막대 끝에 뾰족한 뗀석기를 묶은 사냥 도구 | ☐ |
| 불씨 | 불로 추위를 이기고, 음식을 익혀 먹고, 짐승을 쫓음 | ☐ |
| 찍개 | 한쪽 날을 떼어 내 만든 뗀석기. 찍거나 자르는 데 씀 | ☐ |
| 긁개 | 가죽을 벗기거나 다듬을 때 쓴 뗀석기 | ☐ |
| 슴베찌르개 | 창 끝에 꽂아 쓴 뗀석기. 슴베(꼬리)를 자루에 끼움. 구석기 끝 무렵 도구 | ☐ 교과서에 없으면 빼거나 바꾸기 |

## 3. 부족장 퀴즈 (6문제 중 3문제를 무작위로)

| 문제 | 정답 | 오답 |
| --- | --- | --- |
| 돌을 깨뜨리거나 떼어 내서 만든 도구는? | 뗀석기 | 간석기, 청동기 |
| 주로 어디에서 살았을까? | 동굴이나 막집 | 움집, 기와집 |
| 먹을거리를 어떻게 구했을까? | 사냥과 채집 | 농사, 시장에서 사기 |
| 옮겨 다니며 사는 생활은? | 이동 생활 | 정착 생활, 도시 생활 |
| 불을 써서 할 수 있게 된 일은? | 음식을 익혀 먹기 | 쇠를 녹여 칼 만들기, 흙으로 그릇 굽기 |
| 연천 전곡리에서 발견된 대표적인 뗀석기는? | 주먹도끼 | 빗살무늬 토기, 비파형 동검 |

## 4. 재미를 위해 바꾼 부분 (사실이 아님)

- 유물이 눈과 표정을 가진 정령처럼 움직이고, "시간 괴물"에게 홀려 있다는 설정
- 타임머신, 할아버지, 하람, 변장 기능
- 매머드 사냥의 규칙(창 5번 맞히기, 45초), 채집 규칙(8개 모으기, 35초), 막집 짓기의 스페이스 연타
- 부족장의 "뗀석기 인장", 칭호 "구석기 사냥꾼"
- 기술 이름(내려찍기, 가죽 다듬기 등)은 그 유물의 쓰임새에서 따왔지만 게임용 표현
