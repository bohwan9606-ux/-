# 6·25 전쟁 맛보기 — 게임에 나온 역사 내용 (선생님 검수용)

고칠 곳: `stages/10-korean-war/war.js`

## 1. 작전 지도 이야기 (순서대로)

| 날짜 표시 | 내용 | 확인 |
| --- | --- | --- |
| 1950년 6월 25일 | 북한군이 38도선을 넘어 남쪽으로 쳐들어옴, 6·25 전쟁 시작 | ☐ |
| 1950년 6월 28일 | 전쟁이 일어난 지 사흘 만에 서울을 빼앗김 | ☐ |
| 1950년 8월 | 국군은 낙동강까지 밀려남. 많은 사람이 남쪽으로 피란, 부산이 임시 수도 | ☐ |
| 1950년 8~9월 | 국제 연합(유엔)이 군대를 보내 도움. 낙동강 방어선을 지킴 | ☐ |
| 1950년 9월 15일 | 인천 상륙 작전 | ☐ |
| 1950년 9월 28일 | 서울을 다시 되찾음 | ☐ |
| 1950년 10월 | 38도선을 넘어 압록강 근처까지 올라감 | ☐ |
| 1951년 1월 4일 | 중국군이 전쟁에 끼어들어 다시 밀림, 서울을 다시 내줌(1·4 후퇴) | ☐ |
| 1951~1953년 | 서울을 다시 되찾은 뒤 38도선 부근에서 밀고 밀리는 싸움 | ☐ |
| 1953년 7월 27일 | 정전 협정, 휴전선이 그어짐. 전쟁이 완전히 끝난 것이 아니라 멈춘 것 | ☐ |
| 마무리 | 이산가족, 많은 사람이 목숨을 잃거나 다치고 집·학교·다리가 무너짐, 평화의 소중함 | ☐ |

지도 표시: 북한군(빨강), 국군·국제 연합군(파랑), 중국군(초록) 화살표, 전선(빨간 점선), 휴전선(노란 선). 독도 표시함.

## 2. 미니게임 속 내용

| 미니게임 | 내용 | 확인 |
| --- | --- | --- |
| 피란민 돕기 | 짐을 지고 남쪽으로 피란 가는 사람들에게 물과 주먹밥 나눠 주기 | ☐ |
| 낙동강 방어선 | 거점 이름: 마산, 왜관, 영천, 포항 (실제 방어선 주변 지역). 막아 내는 대상은 사람이 아니라 「시간 괴물」 | ☐ 지명을 넣어도 될지 |
| 인천 상륙 작전 | 인천 앞바다는 물이 빠지면 배가 다니기 어려워 밀물 때를 맞춰야 했음 | ☐ 교과서 수준에 맞는지 |

## 3. 퀴즈 (6문제 중 3문제 무작위)

| 문제 | 정답 | 오답 |
| --- | --- | --- |
| 6·25 전쟁이 시작된 날은? | 1950년 6월 25일 | 1945년 8월 15일, 1953년 7월 27일 |
| 서울을 되찾는 계기가 된 작전은? | 인천 상륙 작전 | 살수 대첩, 귀주 대첩 |

| 1951년 1월 4일 서울을 다시 내준 일은? | 1·4 후퇴 | 3·1 운동, 인천 상륙 작전 |
| 전쟁으로 가족과 헤어진 사람들은? | 이산가족 | 독립운동가, 실학자 |
| 정전 협정 뒤 남북을 나누게 된 선은? | 휴전선 | 38도선, 국경선 |

## 4. 표현 원칙

- 사람끼리 싸우거나 쓰러뜨리는 장면은 넣지 않음. 미니게임은 돕기·지키기·이동하기
- 막아 내는 적은 「시간 괴물」 (게임 전체 규칙과 같음)
- 이산가족 할머니 장면으로 전쟁의 아픔을 짧게 보여 주고 평화로 마무리
